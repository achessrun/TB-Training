TB-1 Prep NEW Rev —

A trial balance is not organized the way financial statements are. It is organized the way the audit is. Once you see that, the groupings that look wrong start looking deliberate.

Accounts receivable is an asset, yet it is filed under Revenue. Accounts payable is a liability, yet it is filed under Expense. Neither is a mistake. This trial balance groups accounts by audit area rather than by financial statement caption, and accounts land together when one set of procedures gives evidence about all of them.

Each group rolls up to a numbered lead schedule. That number is the index reference you write in the corner of every workpaper for that area, and it is how a reviewer finds your work six months later. One group below still has no reference assigned, which is itself worth raising.

Every account carries a note explaining why it is classified where it is, and most carry a second note on what the account puts at risk. Row numbers match the workbook, so you can read this beside the file itself.
